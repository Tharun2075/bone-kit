# Translations
- String tables live in `skeleton/src/i18n.ts` (shared) and `apps/*/src/i18n.ts` (per app). Each has an `en` table and a `te` table.
- Every key exists in both `en` and `te`. Adding a key to one table adds it to the other in the same change.
- No hard-coded user-facing strings outside these files. Components, `aria-label`, `title`, `alt` and error messages all use `t(key, lang)`.
- Keep keys short and group them by screen with a prefix (`mandi.min`, `app.clearAll`). Shared strings use `app.`; app-specific strings use the app's prefix.
- Placeholders such as `{n}` stay identical in `en` and `te`.
- Telugu text needs native-speaker review. Mark unreviewed strings with `// TODO(te)`; do not machine-translate silently.
